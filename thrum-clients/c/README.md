# thrum — C

> _The C reference client. The wire spec is the contract; this is C's mirror of it._

The thrum wire is NDJSON over a Unix socket. This client speaks it from
C, with no dependency beyond libc and a vendored copy of
[jsmn](https://github.com/zserge/jsmn) (MIT) for parsing.

```sh
make          # build
make test     # run the tests
```

## What is generated and what is written

| file | |
|---|---|
| `thrum/chi.h` | the chi registry — generated by `cargo run -p codegen` |
| `thrum/helpers.h` | sigil, rid, dusk, the wane counter, socket resolution — generated |
| `thrum/protocol.h` | every chi's body view — generated |
| `thrum/json.c` | the tone parser and writer — written |
| `thrum/client.c` | the socket loop — written |
| `thrum/jsmn.h` | vendored, MIT, © Serge Zaitsev |

The generated half cannot drift from the Rust registry: `codegen` emits
it, `thrum-core`'s build script refreshes it on every cargo build, and
CI fails if the checked-in copies differ.

The written half is the part a language has to supply for itself. Rust
has `serde_json` and `hum-nest`'s `serve_worker`; Python has `json`;
Go has `encoding/json`. C has neither a JSON library in its standard
library nor a runtime helper, so this directory carries both — the
parser is jsmn's, the writer is thirty lines, because the shapes it
emits are fixed.

## Using it

```c
#include "thrum/client.h"

thrum_client client;
thrum_client_init(&client, NULL);          /* NULL = the default socket */
if (thrum_client_connect(&client) != 0) return 1;
if (thrum_client_hello(&client, "my-bee", "1.0.0",
                       "[\"hello\",\"prompt\",\"chunk\",\"finish\"]",
                       "{\"statefulness\":\"stateless\"}") != 0) return 1;

thrum_client_on_any(&client, on_tone, NULL);
thrum_client_run(&client);
```

The handlers are per-`sid`, with a wildcard for tones that carry no
registered `sid` — the same shape as the Go client.

## The bits worth knowing

- The socket is `HUM_THRUM_SOCK`, else `HUM_SOCKET`, else the
  `runtime.json` rendezvous, else `$XDG_STATE_HOME/hum/thrum.sock`.
- A `sigil` is the 12-hex digest of `nest:sid`; the Rust client and this
  one produce the same bytes, and the test asserts it.
- A `rid` is a 52-char Crockford base32 HumId, ts-prefixed, drawn from
  `/dev/urandom`.
- Lines that are not JSON are dropped, the way humd drops them.
- `clock_gettime` is POSIX, not ISO C: compile with `-std=gnu11`, or
  let the header's `_POSIX_C_SOURCE` do its work.
